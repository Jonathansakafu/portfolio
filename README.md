# Jonathan Sakafu — Portfolio

**Live:** <https://portfolio-seven-dun-d8pz65t7l6.vercel.app>

Personal portfolio site. React + Vite + Tailwind CSS 4, with a React Three
Fiber hero scene and framer-motion for scroll/hover animations.

## Stack

- React 19 + Vite
- Tailwind CSS 4
- React Three Fiber + drei (3D hero scene)
- framer-motion (scroll reveals, 3D tilt project cards)

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
